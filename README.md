# Barangay Legends

A free, open-source idle builder set in a precolonial Philippine barangay.
You are a datu: gather rice and wood, build bahay kubo and palayan, and grow your barangay.

**Play:** https://barangaylegends.fwdp.org (coming soon)

**Status:** Week 1 prototype in progress. See [the roadmap](docs/game-design.md#roadmap).

## Run it locally

The easiest way is GitHub Codespaces: click **Code → Codespaces → Create codespace on main**.

Or on your own machine (Node.js 20+):

```bash
npm install
npm run dev
```

## Contribute

You don't need to know the whole codebase. Most contributions are a single JSON file:
a new building, a blessing, a quest or a lore note. See [CONTRIBUTING.md](CONTRIBUTING.md).
